# Strategy Sandbox

面向宠物险肠胃炎理赔策略的离线仿真工作台。它覆盖材料审核、跨平台本体图谱、事实快照、自然语言策略解析、规则检查、历史回放仿真及案例下钻；前端为原生 HTML/CSS/JavaScript，业务服务由 FastAPI 与 SQLite 提供。

## 项目背景

理赔规则一旦直接上线，可能在短时间内影响大量案件：该赔的不赔、原本不覆盖的案件被放开、人工审核量骤增，或因材料与数据异常造成错误判断。传统做法往往要等规则上线后才能看到结果，业务人员也难以快速定位“哪条规则影响了哪些案件”。

本项目以“上海地区急性肠胃炎案件的可覆盖费用阈值由 200 元调整至 500 元”为示例，提供一个可在上线前反复测试策略影响的理赔沙箱。

## 项目目的

- 在规则上线前，用历史或模拟案件回放候选规则，直观看到它与现行规则相比会带来什么变化。
- 核查策略是否存在致命问题或明显负面影响，例如覆盖范围误放或误收、赔付金额异常、人工审核成本激增、适用范围遗漏和边界条件歧义。
- 让运营人员能够用自然语言提出规则，在确认后得到可执行的策略，并能追溯每一项结论对应的案件、材料与判断依据。
- 为业务、风控和审核人员提供同一套可解释的验证依据；诊疗图片仅作为人工审核与风险线索，不直接决定最终拒赔。

## 演示结果

- 在内置的 320 笔演示案件上，可对比现行规则和候选规则的受影响案件数、覆盖建议变化、核定赔付金额以及人工审核工作量。
- 系统会把发生变化的案件列出，支持逐案查看：原规则与新规则分别为何得出该结论、命中了什么条件、金额如何计算、证据来自哪里。
- 通过 200、200.01、499.99、500、500.01 元等边界样本，可在上线前发现“大于 / 大于等于”等口径错误，避免规则误伤。
- 材料审核、跨平台关联、快照冻结、规则检查、仿真和案例追踪形成可重复的演示闭环；结果用于上线前评估，不作为真实未来赔付或风险预测。

## 快速开始

```powershell
python -m pip install -r requirements.txt
npm start
```

打开 <http://127.0.0.1:4173/>。默认数据库会在首次启动时按固定种子生成 320 笔演示案件；Hash 路由无需额外配置。

## 演示数据与安全说明

仓库有意保留两类作品集演示数据：

- `data/strategy_sandbox.db`：固定种子生成的 SQLite 演示数据库；
- `outputs/019ff16f-ef70-7373-a459-28fcb41e1ec5/信贷策略仿真模拟数据.xlsx`：信贷场景演示数据。

两者均为离线生成的模拟数据，不包含真实客户、宠物、医疗记录或个人身份信息。仓库不会提交上传材料、模型密钥、`.env`、缓存、检查产物或其他数据库文件。删除 `data/strategy_sandbox.db` 后，服务会在下一次启动时重新创建固定的演示数据。

## 可选模型配置

复制 `.env.example` 后可设置 `DATABASE_URL`、`MODEL_BASE_URL`、`MODEL_NAME`、`MODEL_API_KEY` 和 `MODEL_TIMEOUT_MS`。页面输入的模型密钥只保存在当前 FastAPI 进程内存，不会写入浏览器、本地数据库或仓库。

## 项目结构

- `backend/`：FastAPI 服务、规则内核、数据模型、迁移及测试。
- `app-v4.js`、`styles-v4.css`：当前工作台前端。
- `assets/`：低保真宠物险演示素材。
- `data/strategy_sandbox.db`：可直接运行的 SQLite 演示状态。
- `PRODUCT_MVP.md`、`PRODUCT_INTRO.md`：MVP 说明和简历 STAR 产品介绍。
